## What this fork adds

- **Interface (pt-BR):** a Brazilian Portuguese language pack for the web GUI (`packages/client/locale-pt`). Pick it under Settings → General → Language.
- **Documentation and READMEs (pt-BR):** Brazilian Portuguese versions added as parallel files (for example `README.pt.md`) next to the original English content, which is kept intact so the fork stays easy to sync with upstream.

## Translation status

The upstream project evolves quickly. Portuguese translations may lag behind the English source or the Chinese (`中文`) version. When in doubt, treat the **English** original as authoritative.
